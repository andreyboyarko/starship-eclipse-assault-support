# Security reporting

Please report potential vulnerabilities in the support website privately to **huliostudiosupport@gmail.com**, with the subject `Starship Security Report`.

Do not post personal information, credentials, or exploit details in public issues. Include the affected page or version, potential impact, and minimal reproduction steps using only your own data. There is no paid bounty program. This policy does not authorize testing GitHub, Apple, Google, or other third-party systems.
